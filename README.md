# ASLoading

## English

### Description
ASLoading is an iOS application designed to help users learn and practice American Sign Language (ASL). The app utilizes machine learning and computer vision to provide real-time sign language recognition and learning features.

### Features
- Real-time ASL recognition
- Interactive learning interface
- Machine learning-powered hand pose classification
- User-friendly design
- SwiftUI-based modern interface

### Requirements
- iOS 15.0 or later
- Xcode 13.0 or later
- Swift 5.5 or later
